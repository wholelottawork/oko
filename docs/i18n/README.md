## Contributing a translation

1. Open an issue titled `[TRANSLATION] Document name to Language`.
2. Add the document under the appropriate language-code directory.
3. Preserve Markdown structure, links, code, API names, and command examples.
4. Ask a fluent speaker to review technical accuracy and natural wording.
5. Submit a pull request and identify the source document revision.

Use standard language codes in paths, such as `ja`, `ko`, `ru`, `uk`, or `vi`. English documents normally have no language suffix.

Do not translate API, HTTP, REST, JSON, Docker, Kubernetes, Git, GitHub, product names, or identifiers unless the target language has a well-established technical convention.

Machine-assisted translations must receive human review before they are marked complete. Translation maintainers should update their editions when the canonical English document changes.
